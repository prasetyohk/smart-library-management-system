================================================================================
   PANDUAN MEMBUKA & MENGGUNAKAN APLIKASI PERPUSTAKAAN SBTH TK
================================================================================

A. CARA MEMBUKA APLIKASI (MODE RESMI - TANPA JENDELA HITAM CMD):
   Cara 1 (Dari Layar Desktop Komputer):
   - Di Desktop komputer Anda sudah ada ikon aplikasi "Perpustakaan SBTH TK".
   - Cukup KLIK 2X ikon tersebut.
   - Aplikasi akan otomatis berjalan di latar belakang dan browser web (Chrome/Edge)
     langsung terbuka ke: http://localhost:3000

   Cara 2 (Dari Dalam Folder Ini):
   - Cukup KLIK 2X file: "Perpustakaan SBTH.exe"
   - Server otomatis aktif secara senyap (100% tanpa jendela hitam CMD)
     dan browser langsung terbuka ke aplikasi.

B. CARA MENUTUP APLIKASI:
   - Klik kanan ikon kecil Perpustakaan di pojok kanan bawah layar (dekat jam Windows),
     lalu pilih "🛑 Tutup & Keluar Aplikasi", ATAU
   - KLIK 2X file: "HENTIKAN_APLIKASI.bat"

C. CARA PASANG IKON DI KOMPUTER LAIN:
   - Jika Anda memindahkan folder ini ke komputer sekolah lain:
     Cukup KLIK 2X file: "PASANG_IKON_DESKTOP.bat"
   - Ikon aplikasi akan langsung terpasang di Desktop komputer tersebut.

D. IMPORT DATA BUKU DARI EXCEL:
   - Gunakan file: "Template_Master_Impor_Buku_SBTH_TK.xlsx"
   - Isi judul, pengarang, penerbit, ISBN, dan jumlah eksemplar.
   - Buka menu "Manajemen Buku" di aplikasi lalu pilih "Import Excel".

E. BANTUAN & PANDUAN LENGKAP:
   - Seluruh panduan lengkap format Word (.docx) dan petunjuk VPS online
     tersimpan rapi di dalam folder: "DOKUMENTASI_DAN_PANDUAN"
   - File installer Node.js tersimpan di: "INSTALLER_PENDUKUNG"
================================================================================
